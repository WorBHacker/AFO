# AFO

<img src="app/ui/logo.png" width="96" alt="AFO">

[English](README.en.md) · Русский

Локальная AI-экосистема: **хаб** знает проекты, процессы, терминалы и модели; **лёгкое приложение** на Qt Quick (QML, рисуется процессором — видеокарта остаётся моделям); VS Code, Claude Code и агенты подключаются к хабу. Все решения и этапы — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Структура

| Папка | Что это |
|---|---|
| `hub/` | хаб — фоновый процесс на `127.0.0.1:8765`: API и WebSocket, база, шлюз моделей (llama-swap, Claude, Claude Code, OpenAI, Gemini, DeepSeek, OpenRouter), проекты, терминалы, подтверждения, агенты, MCP-сервер, OpenAI-совместимый сервер |
| `app/` | окно на PySide6: `app/ui/` — Qt Quick (QML), рисует процессор; клиент хаба, сам запускает хаб, если тот не работает |
| `common/` | общий код: пути к данным, логирование |
| `vscode/` | расширение VS Code: открытый файл и команды терминалов — в хаб |
| `installer/` | установщик AFO: сборка папки программы и мастер Inno Setup (`afo.iss`) |
| `tests/` | тесты (pytest) |
| `data/` | база, её копии (`data/backups`: за последние 7 дней и перед обновлением схемы), логи, снимки — создаётся сама, в git не попадает |

## Разработка

Подготовка окружения (Python 3.14):

```bash
py -3.14 -m venv .venv
.venv/Scripts/python.exe -m pip install -e ".[hub,app,dev]"
```

Точные версии, с которыми AFO собран и проверен, — в `requirements.lock`; поставить ровно их:

```bash
.venv/Scripts/python.exe -m pip install -r requirements.lock -e . --no-deps
```

Проверки:

```bash
.venv/Scripts/ruff.exe check .
.venv/Scripts/ruff.exe format --check .
.venv/Scripts/python.exe -m pytest
.venv/Scripts/python.exe -m pytest -m stress       # стресс-стенд (~3 мин): цифры старта, длинного чата, большого проекта, терминала
.venv/Scripts/pip-audit.exe -r requirements.lock   # известные уязвимости зависимостей (спрашивает базу PyPI)
```

Запуск окна: двойной щелчок по `AFO.cmd` (без консоли) или

```bash
.venv/Scripts/python.exe -m app
```

Окно само запускает хаб, если он не работает; после закрытия окна хаб продолжает работать. Хаб вручную:

```bash
.venv/Scripts/python.exe -m hub
.venv/Scripts/python.exe -m hub stop
```

Установщик — обычный мастер Windows (язык, папка, ярлыки, «Запускать хаб при входе в Windows»), ставит AFO для
текущего пользователя в `%LOCALAPPDATA%\Programs\AFO` без прав администратора. Собирается так (Inno Setup 6 — один раз):

```bash
winget install --id JRSoftware.InnoSetup -e --scope user
.venv/Scripts/python.exe -m installer.build            # -> build/dist/AFO-Setup-<версия>.exe
```

Внутри — встраиваемый Python с python.org (sha256 сверяется с опубликованным), библиотеки строго по
`requirements.lock` и код из `hub`, `app`, `common`; собранная папка проверяется (`python -m app --smoke`) до упаковки.
Установщик пока без цифровой подписи: Windows при первом запуске предупредит — «Подробнее» → «Выполнить в любом
случае». Удаление — в «Установленных приложениях»; данные и модели остаются, если не попросить их удалить.

Вернуть базу из копии — при остановленном хабе и закрытом окне (прежняя база тоже сохранится копией):

```bash
.venv/Scripts/python.exe -m hub db restore             # список копий
.venv/Scripts/python.exe -m hub db restore ИМЯ_КОПИИ
```

Ключи API (Anthropic, OpenAI, Google Gemini, DeepSeek, OpenRouter, Tavily, Brave Search), адрес своего SearXNG и токен
Telegram-бота задаются в окне:
«Подключения» (Ctrl+Shift+K или «Настройки → Открыть подключения…»). В первый раз окно просит придумать пароль
подключений — без него ключи не добавить, не заменить и не удалить. Ключи хранятся в диспетчере учётных данных
Windows и из хаба не выходят. То же из консоли (спросит пароль, если он задан):

```bash
.venv/Scripts/python.exe -m hub key set anthropic_api_key
.venv/Scripts/python.exe -m hub key status
```

Забыли пароль — `python -m hub connections reset`: сбрасывает его вместе со всеми сохранёнными подключениями.

Там же, в разделе «Серверы MCP», подключаются внешние серверы MCP — командой (`npx -y @modelcontextprotocol/server-…`,
`uvx …`) или адресом. Их инструменты получают новые чаты и задачи агента: что только читает — без вопроса, остальное —
через подтверждение по классу действия, который можно поменять у каждого инструмента.

Там же — «Почта для агента» (любой ящик по IMAP/SMTP с паролем приложения: агент читает письма и отправляет только
после вашего «да» на карточке) и «Ключи API для агента» (ключ уходит только на свой сайт, модель его не видит).

Автономный агент может управлять окнами программ, которые вы разрешили в «Настройки → Программы для агента»: видит их
элементы (UI Automation), нажимает и вводит — после вашего подтверждения, поля паролей и оплату не трогает. Пока он
действует, вокруг окна рамка и полоса «Стоп»; остановить из любого места — Ctrl+Alt+End или меню значка в трее.

Задачу агенту можно поставить и на потом: в форме новой задачи — «Когда: по времени» (каждый день, по дням недели,
каждые N часов) или «по событию» (новый файл в папке, сообщение вашему Telegram-боту). В тихие часы (по умолчанию
23:00–08:00, «Настройки → Автономный агент») задачи не начинаются, а сообщения агента ждут утра.

Агент-координатор (в его профиле — «давать задачи пачкой, параллельно») раздаёт части задачи другим агентам сразу:
облачные идут вместе, локальные — по одной, видеокарта одна; задача, что ждёт другие, получает их результат. Каждый
пишущий агент правит свою копию проекта, у задачи могут быть критерии — их проверяет судья режима «Цель», до трёх
кругов. У прогона координатора над полем ввода — полоса «Подзадачи» и доска, а в проект правки переносит только ваше
«Применить всё».

На компьютере, где локальных моделей ещё нет, окно само откроет «Первый запуск»: покажет видеокарту и память, скачает с GitHub подходящую сборку llama.cpp и llama-swap (с проверкой sha256), запустит их и предложит первую модель для разговоров, кода и картинок. Открыть его снова — «Настройки → Мастер первого запуска…».

Локальную модель можно поставить из окна: «Настройки → Установить локальную модель…» (или последний пункт выбора
модели). В «Подборке» для каждой модели уже выбран вариант, который лучше всего пойдёт на этом компьютере, и сказано,
поместится ли он в видеопамять; «Поиск на Hugging Face» находит любую модель GGUF. Хаб скачивает её на самый быстрый
диск со свободным местом (большой файл — кусками в несколько соединений, с докачкой и проверкой sha256), записывает в `config.yaml` llama-swap (копия прежнего —
рядом) и пробует запустить; «Удалить» убирает и файлы, и запись. Для закрытых моделей нужен токен Hugging Face в
«Подключениях».

Обновления — «Настройки → О программе»: AFO сама смотрит раз в полдня, нет ли на GitHub версии новее (это можно
выключить), скачивает установщик по кнопке (sha256 сверяется) и после вопроса ставит его поверх: окно закрывается и
открывается уже новой версией, данные и модели остаются. Рабочую копию кода обновляют через `git pull`.

Язык окна — русский или английский: «Настройки → Язык · Language». Без выбора AFO говорит на языке установщика, а
если его не было — на первом из языков Windows, который знает.

Все настройки можно сохранить одним файлом и загрузить на другом компьютере: «Настройки → Перенос настроек». Ключей, паролей и разговоров в файле нет; перед загрузкой видно, что изменится, и загрузка ничего не удаляет.

Если что-то не работает — «Настройки → Хаб → Проверить систему…»: что в порядке, что нет и что делать; там же «Собрать журналы для поддержки» (без ключей и разговоров).

Своя папка AFO — `%LOCALAPPDATA%\AFO` (данные, движки, инструменты); если в папке проекта уже есть `data`, данные остаются там, как и в `%LOCALAPPDATA%\LocalChat`, если там уже есть данные (так папка звалась до 2026-11-04). Логи — в `<данные>/logs/<компонент>.log`; «Настройки → Хаб → Открыть папку данных». Папку данных можно переопределить переменной `LOCALCHAT_DATA_DIR`, свою папку — `LOCALCHAT_HOME`. Где конфиг llama-swap и чем его запускать — «Настройки → Запуск».

Окно приносит свои шрифты и значки: Inter и JetBrains Mono (SIL OFL 1.1) — в `app/ui/fonts`, значки Lucide (ISC) —
в `app/ui/icons`; лицензии лежат рядом.

## Claude Code и подписка

AFO не входит в аккаунт Claude и не просит ни пароля, ни токена. Чаты с моделью «Claude Code» запускают ваш
собственный `claude` — официальный CLI Anthropic в том виде, в каком его выпустила Anthropic, — в который вы сами вошли
через страницу Anthropic: он работает по вашей подписке или вашему ключу API, его токены AFO не читает и не хранит.
Другим программам Claude Code через AFO недоступен: OpenAI-совместимый сервер хаба его не предлагает, а сам хаб слушает
только `127.0.0.1`. AFO не связана с Anthropic и не одобрена ею.

Лимиты подписок Pro и Max рассчитаны на обычную работу одного человека. Агенты по расписанию, режим «Цель» и экзамен
моделей могут запускать Claude Code часто и без вас — для такой работы надёжнее модель Claude по ключу API
(«Подключения»). Условия Anthropic: [Legal and compliance](https://code.claude.com/docs/en/legal-and-compliance),
[Usage Policy](https://www.anthropic.com/legal/aup).
