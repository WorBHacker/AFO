# AFO для VS Code

Сообщает хабу AFO на этом компьютере, что вы делаете в VS Code:

- **открытый файл и строку**: модель в чате, к которому подключён этот проект, видит «в VS Code открыт src/app.py:42»;
- **команды терминалов**: команда, код выхода и конец вывода (до 25 строк, ключи и пароли хаб прячет). Неудачная
  команда попадает в ленту хаба и в следующий ответ модели вместе с концом вывода.

Расширение только сообщает. Оно ничего не читает из хаба, ничего не меняет в VS Code и отправляет данные только на
`127.0.0.1`. Если хаб не запущен, сообщения просто пропадают.

Команды из терминалов видны, когда в терминале работает shell integration VS Code: в PowerShell, bash и zsh она
включается сама.

## Установка

1. Токен для расширения: `python -m hub token create vscode` (печатается один раз).
2. Установить расширение: `code --install-extension localchat-0.1.0.vsix` (файл собирается командой
   `npx @vscode/vsce package --skip-license --allow-missing-repository` в этой папке).
3. В VS Code: палитра команд → «AFO: задать токен хаба» → вставить токен. Он хранится в хранилище секретов VS Code.

«AFO: связь с хабом» показывает, всё ли в порядке. Настройки: `localchat.enabled`, `localchat.hubUrl` (только
этот компьютер), `localchat.sendOutput`.
