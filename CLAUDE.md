# Инструкции для Claude

Работай строго по архитектуре и правилам из `TechDoc.md`.

## Протокол взаимодействия:
1. **Правило первого ответа (Zero-Code):** В первом сообщении код решения не генерировать. Сначала проведи аудит затронутых файлов, выпиши сигнатуры и точки риска.
2. **Уточнение требований:** Если в задаче есть критическая неопределенность или риск сломать соседние модули, задай от 1 до 3 точечных вопросов перед началом работы. Не выдумывай очевидные вопросы ради количества.
3. **Защита Windows & Asyncio:** Все изменения терминалов, config.yaml и базы проверяй на гонки процессов, блокировки дескрипторов и совместимость с Windows.
4. **Тесты:** Никаких фиктивных моков для системных модулей. Проверять интеграцию реальными процессами.
